关于github pages 静态博客搭建

做个博客把平时阅读时的感悟总下记录下来

个人博客与公众号等还是有一些不同,这里可以更自由的发挥,不受限制:

Github pages 刚好满足我当下的需求

部署方法:

在 https://www.github.com 注册一个帐号

添加一个仓库

详细可以看官方的参考文件 Quickstart for GitHub Pages

添加好以后是一个空博客,需要本地弄一个静态文件托管,然后把静态文件再上传到github pages才可以有内容
